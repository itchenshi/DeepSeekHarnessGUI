## 简介模板

> 项目地址（GitHub 主仓库）：https://github.com/itchenshi/DeepSeekHarnessGUI
> Gitee 镜像：https://gitee.com/itchenshi/DeepSeekHarnessGUI
> GitCode 镜像：https://gitcode.com/itchenshi/DeepSeekHarnessGUI
> 安装包（含 Windows / macOS / Linux）：https://github.com/itchenshi/DeepSeekHarnessGUI/releases
>
> DSH GUI 是 DeepSeek Harness（DeepSeek 开源的 Agent 框架）的开源桌面壳：
> ✅ 零安装：安装包自带便携 Node，不用装 Node、不用敲命令，解压就能用
> ✅ 托盘常驻：关掉窗口任务不会丢，随叫随回；内存会话，登录态不落盘
> ✅ 引擎自动更新：启动 + 每 30 分钟检查，询问 / 静默 / 仅提示三档策略
> ✅ 插件管理：「安装」与「启用」分离，且与 Harness 页面插件市场双向实时同步
> ✅ 用量/余额：会话标题旁直接显示 OpenCode Go 套餐用量或 DeepSeek 账户余额
> ✅ 多语言与主题：跟随系统 / 中文 / English，主题跟随 Harness，均免重启
> ✅ 数据目录可控：默认 ~/.dsh，可切到应用目录并自动迁移
>
> 内核 100% 是官方引擎，壳只补「运行体验」这一层。
> 开源（MIT）｜非官方独立项目，与 DeepSeek Harness 官方无隶属关系｜欢迎 Star / Issue
> 本期版本：v0.3.0
