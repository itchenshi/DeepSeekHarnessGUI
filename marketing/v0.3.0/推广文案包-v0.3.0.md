## 四、通用注意事项

- **合规表述**：每篇都保留「MIT · 非官方独立项目 · 与 DeepSeek Harness 官方无隶属关系」一句话，减少争议；
- **禁用词**：避免「最强 / 第一 / 无敌 / 秒杀」等绝对化用语（各平台审核敏感词）；
- **图片**：统一用本目录截图（勿引用本地路径），或上传图床；英文平台用 `-english.png` 系列；
- **链接纪律**：除简介、文末与置顶评论外不放硬广；HN/PH 类社区不贴二维码；
- **版本一致性**：所有文章内容以仓库最新 `README.md` 为准（当前 **v0.3.0**）；引擎检查间隔为**固定 30 分钟**、安装包以 **GitHub Releases** 为准；
- **附件说明**：**Gitee 会同步挂载 Windows 产物**（NSIS 安装包 + 便携 zip）；**GitCode 附件能力受限，不挂安装包**，正文指向 GitHub Releases。三平台仓库互为镜像；
- **本期要讲准的两件事**：①「安装」与「启用」是两个独立状态，**关掉不等于卸载**；②「启用」开关与 Harness 页面的插件市场是**双向实时同步**的。这两点最容易写错，发布前对照 README 核一遍；
- **迭代**：发布后收集评论高频问题，回填到 README 的 FAQ 与下一版文章。
