## 1. V2EX「分享创造」帖

**标题候选（三选一）**
1. DeepSeek Harness 没有桌面端，于是我写了个开源的 Electron 壳（附下载）
2. 给 DeepSeek Harness 套了个壳：自动更新引擎 + 系统托盘 + 数据目录，三平台安装包
3. 分享一个 AI Agent 桌面壳：不依赖浏览器、自动保持最新引擎的 DSH GUI

**正文（Markdown 直接可贴）**

> 用了 DeepSeek 开源的 Agent 框架 Harness 一段时间，能力强是强，但工具链体验差点意思：Web UI 开在浏览器标签页里、升级全靠手动 `npm`、数据目录和一堆配置混在一起、关掉窗口=任务没了。
>
> 所以写了 **DSH GUI** —— 一个纯粹的老实人壳（非官方，内核 100% 官方 Harness）：
>
> - 内嵌 `dsh web`（spawn `--no-open --port 0`，解析带认证的 loopback URL），不占浏览器
> - 每次启动全新会话：内存会话，cookies 不落盘，退出时清理整个进程树
> - 启动 + 每小时检查 npm registry，发现新版默认询问，可静默更新 / 仅提示，右下角持久角标
> - 数据目录默认 `~/.dsh`，可切到应用目录并自动迁移
> - 外观跟随 Harness 主题（light / dark / system）
> - 系统托盘：打开窗口 / 设置 / 退出，关窗默认隐藏到托盘
> - 打包捆绑便携 Node，终端用户零安装；Windows / macOS / Linux
>
> 安装包直接下：[GitHub Releases](https://github.com/itchenshi/DeepSeekHarnessGUI/releases)
> 国内镜像：[Gitee](https://gitee.com/itchenshi/DeepSeekHarnessGUI)
>
> 【贴 1 张主窗口截图 + 1 张托盘菜单截图】
>
> 两个设计取舍，欢迎拍砖：
> 1. 坚持「壳纯启动器、不 fork 魔改」，因为官方迭代太快，fork 只会永远落后；
> 2. Intel macOS 的便携 Node 用 `DSH_NODE_ARCH` 在 Apple Silicon runner 上交叉打包，避免「套对壳、套错架构」。
>
> 求 star 更求 issue：新项目最需要的，是「哪里体验很怪」的真实反馈。

## 4. Product Hunt（英文）

**Name**: DSH GUI
**Tagline**: DeepSeek Harness, now a real desktop app — embedded Web UI, always-latest engine.
**URL**: https://github.com/itchenshi/DeepSeekHarnessGUI
**Topics**: Artificial Intelligence · Developer Tools · Open Source · Desktop Apps

**Description（正文一段，可整段粘贴）**

> DSH GUI is an open-source (MIT) desktop shell for DeepSeek Harness, DeepSeek's agent framework. Instead of living in a browser tab, Harness's Web UI runs inside a real native window: a fresh in-memory session on every launch (no cookies on disk), automatic engine updates checked against the npm registry at startup and hourly (ask / silent / notify policies with a persistent toast), a portable data directory (`~/.dsh` by default, switchable to the app folder with one-click migration), Harness-following light/dark theme, and a system tray so closing the window never kills your agent. Installers bundle a portable Node, so end users don't need Node or npm. Windows / macOS (Intel + Apple Silicon) / Linux, built in CI for every release.

**First comment（自评，发完立刻跟帖）**

Release CI builds all three platforms; the macOS Intel package is cross-compiled with a matching x64 portable Node. Very open to feedback on the auto-update UX.

## 5. Show HN（英文）

**Title**
Show HN: DSH GUI – a desktop shell for DeepSeek Harness (embedded Web UI, auto-updating engine)

**Body（自述帖，HN 风格：what / why / how）**

> DeepSeek's agent framework Harness ships a nice Web UI, but using it daily in a browser tab felt wrong: sessions vanish with the tab, upgrades are manual `npm i` roulette, and data lives in `~/.dsh` mixed with everything else.
>
> So I built DSH GUI — an Electron shell, not a fork:
> - embeds `dsh web` (spawns `dsh web --no-open --port 0`, parses the authenticated loopback URL), no browser involved;
> - fresh in-memory session per launch; cookies never touch disk; kills the whole process tree on exit;
> - checks the npm registry at startup and hourly; three update policies (ask / silent / notify) with a persistent toast;
> - data dir defaults to `~/.dsh`, switchable to the app dir with migration;
> - bundles a portable Node so non-developers don't need Node/npm; installers for Windows / macOS (x64 + arm64) / Linux built in CI.
>
> MIT, non-official (separate from the DeepSeek team). Installers: https://github.com/itchenshi/DeepSeekHarnessGUI/releases
>
> One thing I'd love feedback on: the macOS x64 build is cross-compiled on Apple Silicon runners with a matching x64 portable Node (see `DSH_NODE_ARCH` in the repo). If anyone runs it on an Intel Mac and hits an issue, please file one.
>
> What would you change about the auto-update UX?
